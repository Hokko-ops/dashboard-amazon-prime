**Dashboard de Análise de Clientes Amazon Prime**
Este projeto tem como objetivo fornecer uma análise interativa e visual dos dados dos clientes da Amazon Prime, utilizando a biblioteca Streamlit e Plotly. A dashboard apresenta insights detalhados sobre os planos de assinatura, status de renovação, feedback dos usuários, interações com o suporte e preferências de gênero.

**Funcionalidades**
Filtros interativos: Permite que os usuários filtrem os dados por planos de assinatura, gênero, nível de engajamento e faixa etária.
KPIs: Exibe métricas importantes como o total de clientes, a média de idade, feedback médio e interações com suporte.
Visualizações: Diversos gráficos, incluindo gráficos de pizza, barras, histogramas e dispersão, para insights mais profundos.
Download de dados: Permite ao usuário baixar os dados filtrados em formato CSV.
Tabela interativa: Exibe uma tabela dos dados filtrados para uma análise detalhada.

**Tecnologias Utilizadas**
Streamlit: Para criação da interface interativa.
Pandas: Para manipulação de dados.
Plotly: Para visualizações interativas.
Python: Linguagem principal do projeto.
